# Causal Refactor Contract

The implementation is governed by these non-negotiable conditions:

1. A scored one-step forecast for date `t` uses a history ending at `t-1`.
2. The calibration period precedes the final test period; final-test outcomes never tune features, models, intervals, or trading thresholds.
3. A method label always names the implementation actually used. Missing VMD, CEEMDAN, ARIMA, XGBoost, or LightGBM dependencies stop a full run rather than trigger a substitute.
4. The proposed VMD-LASSO-ARX/LSTM route uses training-only decomposition, ApEn routing, LASSO-selected ARX features, and LSTM only for high-complexity modes.
5. Intervals use only a model’s own preceding out-of-sample residuals.
6. A trade uses the stored origin price and forecast to form a position before the realized origin-to-target return.
7. All eight companies must succeed before outputs are written.
8. The report may consume only the canonical artifacts from a successful current run.

Legacy `outputs/` artifacts remain for archival comparison, but are excluded from execution and report export until regenerated by this design.
